# 📧 Email Spam Classifier Using Machine Learning

## 📌 About the Project
The Email Spam Classifier is a machine learning project that identifies whether a message is Spam or Not Spam (Ham). It analyzes the text entered by the user and predicts the category using a trained machine learning model.

## 🎯 Objectives
- Detect spam messages automatically.
- Classify messages as Spam or Not Spam.
- Reduce unwanted messages.
- Develop a simple and user-friendly application.

## 🛠️ Technologies Used
- Python
- Machine Learning
- Scikit-learn
- Pandas
- NumPy
- Streamlit

## ✨ Features
- Enter email or message text.
- Automatically analyze the message.
- Predict whether the message is Spam or Not Spam.
- Display results through a simple web interface.
